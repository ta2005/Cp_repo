## 📂 Folder Structure

To keep things organized, my solutions are categorized by platform:

* `Codeforces/` - Solutions to Codeforces problemsets and specific contests (e.g., Round 1899, 2167).
* `USACO/` - Solutions for the USA Computing Olympiad, including local `.in` and `.out` test files.
* `CSES/` - Standard algorithm and data structure problems from the CSES Problem Set.
* `Unsorted/` - Miscellaneous practice files, templates, and scratchpads.

## 🛠️ Language & Tools

* **Language:** C++ (primarily C++17/C++20)
* **Editor:** Neovim
* **Compiler:** GCC (`g++`)

## 🚀 How to Run

Most of these files are single-file C++ solutions. You can compile and run any of them using `g++`:

```bash
# Compile the solution
g++ -O2 -Wall solution.cpp -o solution

# Run the compiled executable
